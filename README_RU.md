# Груминг салон — Кинешма

Полностью готовая статическая версия сайта с локальными фото, логотипом, отзывами и одним видео.

## Запись
Форма собирает породу, услугу, желаемую дату, пожелание по времени, имя и телефон. Готовая заявка копируется в буфер, затем открываются сообщения сообщества VK. Сервер также сохраняет заявку в server/bookings.json и при настройке VK API может отправлять уведомление на указанный peer_id администратора; обычная ссылка VK сама по себе не умеет надёжно подставлять произвольный текст в поле сообщения, поэтому сайт копирует готовую заявку перед переходом в сообщения.

## Запуск
Откройте index.html для просмотра сайта. Для работы API: установите Node.js, выполните `cd server && npm install`, настройте `.env`, затем `npm start`.
